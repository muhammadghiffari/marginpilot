# REPO-MAP — target codebase, file level

Derived only from `ARCHITECTURE`, `INTERFACES`, `CONTRACTS`, `AGENT-DESIGN`, `OPTIMIZER`, `UI-SPEC` and `tasks/*`. It adds no new design. **Every file below is `to-create`.**

## How to read this
- **Name:** `S` = the file name is given in a spec; `P` = proposed name (the spec gives only the role). Renaming a `P` file is free; renaming an `S` file needs a spec PR.
- **Tier** is a recommendation for choosing the model/effort, not a spec rule. **Heavy** = money/security logic where a silent bug is costly, or exact-match to another component. **Medium** = well-specified logic with clear tests. **Light** = scaffolding, config, plumbing, presentational UI.
- Owners: A = Dev A, B = Dev B. Refs use the spec file and section.
