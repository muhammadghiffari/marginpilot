# KNOWN RISKS (honest list; extend with anything you discover while building)

Rules: be specific; state the impact and the mitigation actually implemented; state what is **not** handled. Judges reward candor more than claims.

| # | Risk | Impact | Mitigation implemented | Not handled / remaining |
|---|---|---|---|---|
| R1 | Contracts unaudited, written in a day | funds loss on mainnet use | testnet only; Foundry tests + fuzz; adversarial suite | no formal verification, no external audit — **do not use with real funds** |
| R2 | Simulated lending market and admin-set oracle | results don't transfer to real protocols | self-deployed sim documented as a simulation; loss model mirrors sim | real protocol interest, partial liquidations, oracle lag, MEV not modeled |

| R4 | Demo-owner key lives on the server; `/api/mandate/confirm` in `ownerMode: "demo"` has no caller authentication when demo controls are enabled | anyone who reaches a public-facing demo agent could submit a compiler-accepted owner mandate and trigger bounded executor activity, even without compromising the server | this run bound the agent to `127.0.0.1`; the server-key confirm route returns 404 when `demoMode` is false (API test); browser-wallet signing path is signature-verified server-side | **never expose a testnet agent with `ALLOW_DEMO_CONTROLS=true` and a demo-owner key via a public URL**; public mode still needs authenticated admin controls; browser extension E2E not recorded |
| R5 | Gas not counted in on-chain budget | spend slightly above stated "budget" in total cost | tracked off-chain per run and reported separately | no on-chain gas accounting |
| R6 | USD valuation depends on oracle | wrong/stale price mis-sizes limits | freshness and deviation checks; fail closed | oracle compromise out of scope |
| R7 | LLM variance and third-party dependency | inconsistent plan text/choices; provider downtime | numbers from code, gate independent, `ScriptedLlm` for tests, pass^k report | provider outage stops live demo (fallback: recorded run in evidence) |

| R9 | Single chain, single protocol, 2 pools | narrow generality | explicit scope | no multi-chain, no real Aave |

| R11 | EOA-only signature verification | no ERC-1271 smart-account owners | documented | contract-wallet owners unsupported |

| R15 | Public-chain transactions operate on a self-deployed lending **simulator** | reviewers may over-read Sepolia receipts as real-protocol rescues | Sepolia chain 11155111 receipts and deployment are separated from local anvil and in-memory runs; UI labels chain mode `TESTNET` and docs label the market `SIMULATED` | no real Aave/production-protocol integration; testnet S2/S7/kill-switch failure cases not broadcast |
| R16 | Transaction broadcast can fail after the RPC received it but before a hash is returned | an action may be mined without the agent knowing; retrying could double-spend | `submit` returns `unknown` only when it has a hash; the orchestrator reconciles with `getTx` and never resends; a pre-hash RPC error halts the run | no nonce-based recovery for a broadcast whose hash was never observed; operator must inspect the chain |
| R17 | Mainnet guard is a denylist plus local-chain checks | a new/obscure mainnet chain id could slip past the agent/wrapper | both config and deploy/start wrappers reject the common mainnet ids and local ids in testnet mode; deploy requires human-present keystore and funded sender | not an allowlist; a human must still confirm the network before broadcast |
| R18 | Kill-switch/pause API is unauthenticated | any visitor can pause the vault (DoS), though cannot unpause or move funds | rate limits; pause is executor-only on chain; owner unpauses with `cast`/wallet; funds remain owner-withdrawable | no auth token on the public demo; deploy behind a trusted proxy/firewall |
| R19 | Sepolia's observed code-deposit gas cost and 16,777,216 execution ceiling broke Forge-estimated deployment | a new Forge attempt could consume test ETH on failed creations or fail before the vault is deployed | after reconciling failures, this run used explicit per-tx gas limits and a via-IR, size-optimized vault; `deploy-testnet.sh` now refuses Sepolia before RPC/broadcast; receipts and addresses are recorded in `evidence/sepolia-e2e-20261021.json` | no reusable guarded manual-deploy script yet; six simulator contracts in this deployment used pre-optimization compiler settings; do not retry a failed broadcast without checking its receipt and code |
| R20 | The smaller vault implements its own EIP-712 domain hash and low-s signature recovery instead of OpenZeppelin's helpers | an undiscovered crypto/chain-fork discrepancy could allow or reject a mandate unexpectedly | vault tests T09/T09d-g (high-s, recovery-id, length edge cases and a Solidity-vs-viem pinned digest) and signer/replay checks pass; the Sepolia owner-signed mandate mined | unaudited custom implementation; domain separator captures deployment chain id and does not update after a chain-id fork; no ERC-1271 support |
