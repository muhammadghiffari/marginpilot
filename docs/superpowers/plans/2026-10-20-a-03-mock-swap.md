# A-03 MockSwap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** An oracle-priced swap with a fixed 30 bps fee and a broken-switch for failure injection.

**Architecture:** `MockSwap` values `tokenIn` in usd8 via `MockOracle`, applies 3 000 bps to `amountOut`, checks `minAmountOut`, then pulls `tokenIn` and sends `tokenOut` from its own seeded liquidity.

**Tech Stack:** Solidity 0.8.24, Foundry, `MockERC20`/`MockOracle`.

**Spec:** `docs/spec/CONTRACTS.md` §2.4, §4; `tasks/DEV-A.md` A-03.

## Global Constraints

- `feeBps = 30`, constant; `SlippageExceeded` must be the exact error name from CONTRACTS §4.
- `setBroken(bool)` is admin-only; `swap` reverts while broken.
- Oracle-priced: `amountOut = amountInUsd8 * (10000 - 30) / 10000 * 10**decOut / priceOut`.
- The contract holds its own liquidity; tests seed it.

## Review Focus

- Decimal scaling both directions (6→18 and 18→6).
- `minAmountOut` equal to the computed output must pass; one unit more must revert.
- Revert paths must not move tokens.
