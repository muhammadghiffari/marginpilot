# A-04 Sub-steps 1–2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** `MandateVault` auth/pause/withdraw skeleton, then owner-signed mandates via EIP-712 with monotonic ids.

**Architecture:** OZ `EIP712` for the domain, OZ `ECDSA` for recovery, OZ `SafeERC20` for withdrawals. Mandates are stored whole; `nextMandateId` starts at 1 and only ever increases. `setMandateWithSig` lets any relayer submit an owner signature.

**Tech Stack:** Solidity 0.8.24, Foundry, OpenZeppelin v5.0.2 (pinned), `MockERC20`/`MockOracle`.

**Spec:** `docs/spec/CONTRACTS.md` §2.5; `docs/spec/INTERFACES.md` §8.

## Global Constraints

- Error names exactly: `NotOwner, NotExecutor, Paused, MandateInactive, MandateExpired, StaleAction, DeadlineExpired, ZeroAmount, ActionNotAllowed, BorrowForbidden, TargetNotAllowed, AssetLocked, StalePrice, PriceDeviation, PerActionCapExceeded, BudgetExceeded, SlippageExceeded, PostConditionFailed, BadSignature, BadNonce, SignatureExpired`.
- Domain: `name="MarginPilotVault"`, `version="1"`, `chainId`, `verifyingContract=vault`.
- Typehash strings copied verbatim from CONTRACTS §2.5; tests recompute the digest from literal strings.
- `Mandate` field order exactly as CONTRACTS §2.5.
- Arrays hashed per EIP-712 (32-byte element encoding), matching viem in A-08.
- First mandate id is 1; `id != nextMandateId` ⇒ `BadNonce`.
- No `execute`, no calldata path, no `delegatecall` in these sub-steps.

## Review Focus

- `ownerWithdraw` must work while paused and after mandate expiry (no mandate check).
- `unpause` by executor must revert `NotOwner`; `pause` by outsider must revert.
- Replaying the same signature must fail `BadNonce`; expired deadline must fail `SignatureExpired` before signature work.
- The test digest must be built independently from the contract constants.
